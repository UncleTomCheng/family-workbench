# 家庭工作台（Family Workbench）

一个纯静态、零依赖的单页家庭工作台，包含两大模块：

## 💰 财务分析
- **总览**：净资产、投资市值、本月收支 KPI + 资产分布
- **账户资产**：银行储蓄 / 支付宝 / 微信 / 证券账户统一管理，负债记负数自动冲抵
- **收支流水**：随手记账，自动算本月结余率，支持收入/支出筛选
- **投资持仓**：股票、ETF、基金统一算市值盈亏（红涨绿跌）
- **大盘复盘**：内置实战向「复盘六步框架」（指数结构 → 量能 → 情绪温度 → 主线题材 → 赚钱效应 → 次日计划）+ 情绪温度带曲线

## 🌱 小树苗（1-6 岁学龄前培育）
- **成长总览**：宝宝档案（自动算月龄）、最新身高体重、本周培育重点
- **生长发育**：身高 / 体重曲线 + 里程碑分布
- **培育计划**：按 8 个维度分龄设计（营养喂养/睡眠/运动感统/语言/认知/情绪社交/习惯/安全），点状态徽章循环切换 待开始→进行中→已达成
- **成长记录**：时间轴式成长日记
- **育儿锦囊**：分龄专家要点

## 数据说明

所有数据保存在**浏览器本地 localStorage** 中：
- 数据只存在于你当前使用的浏览器里，不上传服务器，清除浏览器数据会丢失
- 换浏览器/设备数据不互通
- 需要数据互通请使用 WorkBuddy 资料库版工作台

## 技术栈

单个 `index.html`，无框架、无构建、无外部依赖。数据层通过一个约 60 行的 localStorage 适配器实现（query / getSchema / addRecord / updateRecord），可替换为任意后端 API。
